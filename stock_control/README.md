# 📦 Stock Control

Um sistema de controle de estoque desenvolvido com **HTML, CSS e JavaScript**, criado para praticar lógica de programação e desenvolver funcionalidades úteis para o gerenciamento de produtos.

## ✨ Funcionalidades

- **Cadastro de produtos:** registre nome, valor, quantidade e categoria.
- **Listagem de produtos:** visualize as informações dos produtos cadastrados.
- **Pesquisa:** encontre produtos pelo nome.
- **Edição de produtos:** atualize as informações de um produto existente.
- **Remoção de produtos:** exclua produtos do estoque.
- **Controle de quantidade:** aumente ou diminua a quantidade de cada produto.
- **Indicadores de estoque:** acompanhe o total de produtos, os itens com estoque baixo e os itens sem estoque.
- **Status visual:** identifique produtos com estoque normal, baixo ou zerado por meio de cores.
- **Armazenamento local:** os produtos ficam salvos no navegador usando `localStorage`, permitindo manter os dados após recarregar a página.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage API

## 🚀 Como executar

1. Clone este repositório ou baixe os arquivos do projeto.
2. Abra a pasta `stock_control`.
3. Abra o arquivo `index.html` em um navegador.

Não é necessário instalar dependências para executar a versão atual.

## 📚 Objetivo do projeto

O Stock Control foi desenvolvido como um projeto de aprendizado, com o objetivo de praticar JavaScript e construir uma aplicação interativa com funcionalidades de gerenciamento de estoque.

Durante o desenvolvimento, foram trabalhados conceitos como manipulação do DOM, eventos, arrays, objetos, funções, filtros, validação de dados e armazenamento local.
