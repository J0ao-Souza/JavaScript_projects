# 🐍 Jogo da Cobrinha

Um jogo da cobrinha desenvolvido com HTML, CSS e JavaScript.

O projeto foi desenvolvido como forma de praticar manipulação do DOM, eventos, arrays, funções, lógica de programação e armazenamento de dados no navegador.

## 🎮 Funcionalidades

- Movimentação da cobra pelas setas do teclado
- Controles na tela para dispositivos menores
- Sistema de pontuação
- Sistema de High Score
- High Score salvo no navegador
- Comida aparecendo em posições aleatórias
- Crescimento da cobra ao comer
- Colisão com as paredes
- Colisão da cobra com o próprio corpo
- Sistema de Game Over
- Layout responsivo

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Font Awesome
- LocalStorage

🧠 O que pratiquei neste projeto

Durante o desenvolvimento deste projeto, pratiquei:

Seleção de elementos do HTML com querySelector() e querySelectorAll()
Manipulação do DOM
Eventos com addEventListener()
Funções com arrow functions
Arrays para armazenar o corpo da cobra
Estruturas condicionais
Loops for
Operadores lógicos
Números aleatórios com Math.random() e Math.floor()
Manipulação de HTML através de innerHTML
Controle de tempo com setInterval()
Armazenamento de dados com localStorage
CSS Grid
Responsividade com Media Queries
▶️ Como executar
Baixe ou clone o projeto.
Abra a pasta no VS Code.
Abra o arquivo index.html no navegador.

Também é possível utilizar uma extensão como o Live Server no VS Code para executar o projeto.

🎯 Objetivo

O objetivo principal deste projeto foi praticar JavaScript através da criação de um jogo funcional, trabalhando principalmente com movimentação, colisões, arrays e atualização dinâmica da interface.
