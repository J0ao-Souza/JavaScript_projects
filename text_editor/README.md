📝 Text Editor

Um editor de texto desenvolvido com HTML, CSS e JavaScript, permitindo formatar textos diretamente pelo navegador.

🚀 Funcionalidades
Negrito
Sobrescrito
Subscrito
Lista ordenada
Desfazer e refazer
Criar e remover links
Alinhamento do texto
Indentação
Títulos de H1 até H6
Seleção de fontes
Alteração do tamanho da fonte
Alteração da cor do texto
Alteração da cor de destaque
🛠️ Tecnologias utilizadas
HTML5
CSS3
JavaScript
Font Awesome
Google Fonts
📂 Estrutura do projeto
text-editor/
├── index.html
├── style.css
├── script.js
└── README.md
▶️ Como executar
Baixe ou clone este repositório.
Abra a pasta do projeto no Visual Studio Code.
Abra o arquivo index.html no navegador.

Também é possível utilizar uma extensão como Live Server no VS Code para executar o projeto.

🎯 Objetivo

Este projeto foi desenvolvido com o objetivo de praticar JavaScript, manipulação do DOM e criação de uma interface de edição de texto utilizando tecnologias web.
