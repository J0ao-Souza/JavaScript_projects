🪙 Cara ou Coroa

Um projeto simples e interativo de Cara ou Coroa, desenvolvido com HTML, CSS e JavaScript.

O usuário pode clicar no botão para virar a moeda, visualizar uma animação e acompanhar quantas vezes saiu Cara ou Coroa.

🚀 Funcionalidades
🪙 Animação de moeda sendo lançada
🟢 Contagem de resultados de Cara
🔵 Contagem de resultados de Coroa
🔄 Botão para virar a moeda
♻️ Botão para resetar os resultados
🎨 Interface estilizada com CSS
📱 Layout centralizado

⚙️ Como funciona

Quando o usuário clica em Virar Moeda, o JavaScript gera um número aleatório entre 0 e 1.

Dependendo do resultado:

1 → Cara
0 → Coroa

Depois disso, uma animação diferente é aplicada à moeda e o contador correspondente é atualizado.

🎮 Como executar
Baixe ou clone o projeto.
Abra a pasta no VS Code.
Abra o arquivo index.html no navegador.
Clique em Virar Moeda.
🎯 Objetivo

O objetivo do projeto foi praticar JavaScript através de uma aplicação simples e interativa, trabalhando principalmente com eventos, números aleatórios, manipulação do DOM e animações CSS.
